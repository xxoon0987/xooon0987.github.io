## 一、導論：資料、任務與 KDD

### 1. Object、attribute、dimension、size、sparsity

資料表的**每一列是 object（物件／資料筆）**，每一欄是 attribute（屬性／特徵）。影片顧客資料表的欄位有 TID、Refund、Marital Status、Taxable Income、Cheat。TID 100 是一個物件，其餘欄位描述它。

- **Size** 是物件數，也就是有幾列。
- **Dimensionality** 是每個物件有幾個特徵欄位。
- **Sparsity** 和有多少「物件－屬性」格子真的有值有關；大量空格表示資料稀疏。
- 類別特徵可分名目類別（顏色、婚姻狀態，沒有順序）與順序類別（低／中／高，有順序但差距不一定等距）。數值特徵可分離散計數和連續測量。

**例子：** 500 位顧客各有 8 個欄位，就是 500 個物件、8 個維度。若欄位值 1、2、3 分別代表台北、台中、高雄，這些數字只是代碼，不能說台北和台中距離為 1。

### 2. KDD 與資料探勘

KDD（Knowledge Discovery in Databases）是從原始資料到知識的整套流程。**資料探勘只是其中尋找模式的一步**。影片流程圖展示資料庫／資料倉儲先經選取、清理整合與轉換，再做資料探勘，之後評估並呈現 patterns。

常見順序：

1. **選取**：挑出與問題相關的資料。
2. **清理與整合**：處理錯值、重複、缺值，合併不同來源。
3. **轉換**：標準化、分箱、建構特徵，讓資料適合演算法。
4. **資料探勘**：用分類、分群、關聯法則等找規律。
5. **評估與呈現**：確認規律可信、能回答原問題，再讓人使用。

**例子：** 商店想減少缺貨，不能只跑模型；要先把不同分店的商品編碼統一，修正交易時間，再找銷售模式，最後檢查模式是否能幫忙安排補貨。

### 3. 監督／非監督，以及 underfit／overfit

若訓練資料有正確答案標籤，就是**監督式學習**；要預測類別叫分類，要預測數值叫迴歸。沒有目標標籤、要自己找群或規則，則是**非監督式學習**，例如分群、關聯法則、降維。

影片也用模型曲線說明：模型太簡單，連主要規律都抓不到，是 **underfitting（欠擬合）**；模型太複雜，把訓練資料的雜訊也記起來，是 **overfitting（過度擬合）**。理想模型要學到可延伸到新資料的規律。

## 二、資料距離與相似度

### 1. 實數向量距離

把一筆資料寫成向量，例如顧客 A = (年齡 20、消費 500)，顧客 B = (30、700)。

- 歐氏距離：直線距離，`sqrt(各維差的平方和)`。
- 曼哈頓距離：沿格子路走，`各維差的絕對值相加`。
- 這些距離都會受單位影響。金額若以元表示，往往會比年齡數字大很多；未先縮放時，金額容易主導距離。

**例子：** (1,1) 與 (4,5) 的歐氏距離是 5，曼哈頓距離是 7。兩個數字代表不同的「如何量距離」，不是誰一定正確。

### 2. Cosine similarity

影片用文件的詞頻向量做例子：每一維是一個字詞，數字是它在文件出現幾次。Cosine 看兩個向量的**方向／比例**，不直接看總量：

`cosine(A,B) = A·B / (||A|| ||B||)`

**例子：** 文件甲提到「球鞋、跑步」各 10、5 次，文件乙各 100、50 次。兩者長度差很多，但字詞比例一樣，所以方向相同、cosine 相似度高。適合比較文章主題或顧客偏好。

### 3. Jaccard 與二元屬性

Jaccard 看兩集合共有多少、佔兩集合聯集多少：

`J(A,B) = |A∩B| / |A∪B|`

影片例圖共有 3 個元素、聯集 8 個，因此相似度 `3/8`。完全相同是 1，完全沒有交集是 0；交換 A、B 不改變結果。

比較二元資料時，令：`q`=兩者皆 1，`r`=A=1/B=0，`s`=A=0/B=1，`t`=兩者皆 0。

- **對稱二元屬性**：0 和 1 同樣重要，例如兩個人是否有某種同等重要的偏好。Simple Matching 會把 `q` 與 `t` 都算相同，similarity=`(q+t)/(q+r+s+t)`。
- **非對稱二元屬性**：1 是重要、稀有的出現，0 是一般的缺席，例如罹患罕見疾病、買了某商品。Jaccard 忽略共同為 0，similarity=`q/(q+r+s)`。

**為什麼要分？** 若兩人都沒買 999 種商品，只買了不同的一種，算上大量共同的 0 會讓兩人看起來超相似；對購物偏好而言這會誤導。

## 三、降維：PCA、Fisher、Kernel 與流形

### 1. 好的投影與 PCA

投影是把很多欄位轉成少量新座標。**好的投影要保留和目標有關的資訊**。PCA 不看類別答案，找出資料變異最大的方向；新的主成分互相垂直。

PCA 把共變異矩陣做特徵分解。第 j 個主成分的解釋變異比例約為：

`λ_j / (所有特徵值總和) × 100%`

**例子：** 身高公分和身高英吋高度重複，PCA 可以把兩欄濃縮成一個主要身高方向。若最大變異來自背景亮度，這個方向未必最能分開兩種照片類別。

### 2. Fisher's Linear Discriminant（FLD／LDA）

影片把兩個已知類別投影到一條線上作比較。直接投影到 x1 或 x2 可能讓紅綠點混在一起；Fisher 選一個方向，讓**類別中心距離大、各類內部散布小**。其概念目標可寫成：

`投影後類間散布 / 投影後類內散布` 越大越好。

**例子：** 紅綠兩群身高重疊很多、考試分數差很多；要預測及格類別，Fisher 會偏好考試分數方向。PCA 則只看哪個方向整體變異最大，可能選到不能區分及格與否的方向。

**易錯：** PCA 是無監督的最大整體變異；Fisher 用已知類別訊息做判別，兩者即使都降維，目的也不同。機率式 LDA 常再假設各類條件分布為高斯、共用共變異矩陣；這個高斯假設不是所有 Fisher 投影概念本身的必要條件。

### 3. SVD、MDS、Kernel PCA、LLE、Isomap

影片的降維大綱列出 PCA、MDS、SVD、Kernel PCA、LLE、Isomap：

- **SVD** 將資料矩陣拆成方向與強度，保留大奇異值可做低秩近似／壓縮；中心化資料的 SVD 和 PCA 密切相關。
- **MDS** 嘗試把資料放到低維平面，同時保留原本資料點間距離。
- **Kernel PCA** 用核相似度做非線性 PCA。
- **LLE** 保留每一點如何由近鄰加權重建，再找出符合這些近鄰關係的低維表示。
- **Isomap** 先用近鄰圖估計流形上的測地距離，再用低維座標保留這些距離。

這幾個名稱在影片的降維大綱出現；是否都列入考試，要再對照老師的正式重點表。

### 4. Kernel trick

影片用三個一維點 `x=0,1,2` 說明：在一維直線上，中間點與兩端點無法用一條直線分成「中間」和「兩端」；經映射 `φ(x)=(x², √2x)` 到二維後，三點成為 `(0,0)、(1,√2)、(4,2√2)`，便可以用直線分開。

高維映射可能很昂貴。Kernel trick 讓某些只需要內積的演算法，直接計算核函數，不必列出全部高維座標。影片列出 Gaussian 與 hyperbolic tangent 核。SVM、Kernel PCA、Kernel K-means 都可能用到核函數。

### 5. Geodesic distance 與 manifold

測地距離是在資料所在的彎曲表面上，連接兩點的最短曲線長度。球面上沿大圓走的路徑是測地線；沿小圓繞一圈通常更長。把紙捲成瑞士捲時，空間直線距離可能很短，但沿著紙面走很遠。

「Intra-view Manifold-respecting Discriminant Information」可按字面記成：同一種資料視角內，盡量保留流形／近鄰結構，同時留下類別辨識資訊。影片重點表只有此標題，沒有完整公式；因此考觀念時先抓住「局部鄰近結構＋類別可分性」。

## 四、關聯法則：把影片例題完整走一次

### 1. 交易資料與 Apriori

購物交易的每一列可視為一個商品集合，不一定有購買數量。影片例子：

| TID | 商品 |
|---|---|
| 100 | 1, 3, 4 |
| 200 | 2, 3, 5 |
| 300 | 1, 2, 3, 5 |
| 400 | 2, 5 |

最小支持度 50%，4 筆交易中至少出現 2 次才算頻繁。第一次掃描得到：`{1}:2、{2}:3、{3}:3、{4}:1、{5}:3`。`{4}` 不頻繁，因此所有含 4 的較大候選組合也可剪掉。頻繁二項組合有 `{1,3}:2、{2,3}:2、{2,5}:3、{3,5}:2`。再往上，`{2,3,5}` 的三個二項子集都頻繁，計算後支持度是 2，所以保留。

這就是 Apriori 的 downward closure：一個集合不頻繁，它的超集合不會比它更頻繁；反過來，集合頻繁時所有子集也必須頻繁。

### 2. Maximal vs. Closed

影片另一張項集格狀圖設定最小支持度 2，標出 9 個 closed、4 個 maximal 項集。

- **Maximal frequent itemset**：已沒有任何更大的頻繁超集合。它是最大邊界，但中間小項集的支持度資訊可能不完整。
- **Closed frequent itemset**：已沒有支持度相同的更大超集合。它能保留更多支持度資訊。

記法：**Maximal 問「還能不能變大且仍頻繁？」；Closed 問「變大後支持度會不會完全一樣？」**

### 3. Support、confidence 為什麼會誤導

影片的咖啡店例子有 10,000 人：7,500 人買咖啡、6,000 人買茶、4,000 人兩者都買。

規則「買茶 → 買咖啡」：

- Support = 4,000 / 10,000 = **40%**。
- Confidence = 4,000 / 6,000 = **66.67%**。
- 但全部顧客中本來就有 75% 買咖啡；茶客買咖啡的比例 66.67% 反而比基準 75% 低。
- Lift = 66.67% / 75% ≈ **0.89**，小於 1，兩商品在這組資料裡是負向關聯。

反向「買咖啡 → 買茶」的 confidence 是 4,000/7,500 = **53.33%**；全部客人的買茶基準率是 60%，它也低於基準。這說明高 confidence 不是「有因果」，也不能脫離 consequent 的基準率判斷關聯強度。

### 4. FP-tree

FP-tree 會先統計頻繁商品並排序，再把交易中共同前綴壓進一棵帶計數的樹，後續從條件樣式基底遞迴挖掘。它的重點是避免 Apriori 產生並反覆掃描大量候選集；它仍可能在模式很多時需要大量運算與記憶體。

## 五、前處理：缺值、分箱、標準化、卡方

### 1. Missing values

影片問「如何處理缺值」，並提醒把所有空格都人工填完可能非常費時，且若缺值不多、填法不可靠，處理結果也可能很差。實務方法包括刪除缺值很少的列／欄、用平均數或中位數／眾數補、用模型預測補，或把缺值本身當一種狀態。應看缺值比例、缺失原因和分析目的選方法。

**例子：** 病患年齡少數漏填可用訓練資料的中位數補；若「是否填寫問卷」本身代表某種行為，缺失狀態可能也有資訊。補值參數應只由訓練資料估計，避免測試資料洩漏。

### 2. Normalization

把量尺不同的欄位調到可比較範圍，例如身高公分與年收入元。Min-max 常縮放到 0–1；z-score 用 `(x−平均)/標準差`。KNN、K-means、距離相似度常特別需要注意尺度；樹模型通常不像距離模型那麼依賴數值單位。

### 3. Binning：影片數列

影片使用價格：`4, 8, 15, 21, 21, 24, 25, 28, 34`。

- **Equal-width（等寬）**：值域分 N 個同寬區間，寬度 `(最大值−最小值)/N`。若極端值很遠，會把大多數資料壓在少數箱子裡；偏態分布不一定處理得好。
- **Equal-depth／equal-frequency（等深）**：讓每箱筆數大致一樣，但區間寬度不同。三箱可分成 `[4,8,15]`、`[21,21,24]`、`[25,28,34]`。

等寬是「每箱跨度一樣」，等深是「每箱資料量差不多」，不要混淆。

### 4. Chi-square

卡方比較觀察次數 `O` 與「兩變數無關」時預期次數 `E`：

`χ² = Σ (O−E)²/E`，而 `E = (列合計×欄合計)/總數`。

例如看「是否買茶」和「是否買咖啡」有沒有關聯，先由邊際合計算出假設獨立時每格應有多少，再比較實際值。差距愈大，反對「完全無關」的證據愈強；卡方不直接表示關聯方向，也不是模型準確率。

## 六、分群：型態、演算法與如何選 K

### 1. Partitional vs. Hierarchical

影片明確比較兩種結果：**Partitional clustering** 把資料切成互不重疊的群，每筆資料剛好屬於一群；**Hierarchical clustering** 產生巢狀群組，表示成樹狀圖，可在不同高度切成不同數量群組。

### 2. AGNES、DIANA、linkage

- **AGNES／Agglomerative（凝聚）**：一開始每點自己一群，再反覆合併最近群組，直到成一群或達停止條件。
- **DIANA／Divisive（分裂）**：一開始全部在一群，再逐步把群拆開。
- 合併群之後要更新距離矩陣，答案依 linkage 規則而不同：single 取兩群最近點距離；complete 取最遠點距離；average 取所有跨群點距離平均；Ward 選擇讓群內平方誤差增加較少的合併。

**影片白板式小例：** A={1,3}、B={6,9}，跨群距離 5、8、3、6。Single 距離是 3；complete 是 8；average 是 5.5。題目若問合併後表格，先圈出使用哪一種 linkage，再重算新群距離。

樹狀圖切割時，切得越低通常群數越多；層級式方法可以先做樹，再決定切幾群，不一定要一開始指定 K。

### 3. K-means、SSE、Elbow 與限制

K-means 重複做兩步：把點分配給最近中心；把中心更新成群內平均。它用 SSE（群內平方距離總和）衡量緊密度。K 增大時 SSE 幾乎一定下降；當 K 等於資料筆數時，每點一群，SSE 可變 0，所以不能單純挑「SSE 最小」的 K。影片建議看曲線的 **elbow／knee**：從快速改善轉為改善有限的轉折。

K-means 快、可擴充，但：需設定 K；需要數值和距離；對初始化、尺度、離群值敏感；偏好球狀／圓形、大小相近的群，對月牙、環形等非球狀群可能切錯。

### 4. Kernel K-means、DBSCAN、譜分群、EM

- **Kernel K-means** 用核相似度把 K-means 的群中心想法帶到特徵空間，可改善某些非球狀群；仍要選 K 和核參數。
- **DBSCAN** 用 ε 鄰域與 MinPts 找密集連通區。核心點可擴張群、邊界點可加入但不繼續擴張，離群稀疏點標為 noise；不必先給 K，能抓任意形狀，但不同密度群和高維資料較難。
- **譜分群** 先建立相似圖 W，計算度矩陣 D 與拉普拉斯 `L=D−W`（也有正規化版本），取相關特徵向量，把資料放到新座標後再分群；善用圖上的連結結構，因此能分開某些彎曲群。
- **EM** 常用於高斯混合模型。E 步估每點屬於各群的機率（軟分配），M 步據此更新群的參數，反覆進行。它不像 K-means 每點只硬分到一群，且可能受初始化影響落在局部最佳。

## 七、決策樹、混淆矩陣與模型評估

### 1. Entropy 與 Information Gain

熵衡量類別有多混雜：`H(S)=−Σ p_i log₂ p_i`。全是同一類時熵 0；二類各半時最不確定、熵 1 bit。

影片丟硬幣例子：14 次有 9 正面、5 反面，熵約 `−(9/14)log₂(9/14)−(5/14)log₂(5/14)=0.94`。若正反各 7 次則熵 1；若每次都正面則熵 0。

Information Gain = 父節點熵 − 子節點熵的加權平均。切完越純，通常增益越高。它可能偏好多值屬性；Gain Ratio 再除以切分本身的資訊量，減少這種偏好。

### 2. Gini 與影片天氣資料

Gini 是分類不純度：`Gini(S)=1−Σ p_i²`；純節點為 0，類別越混雜值越大。影片資料集 14 天，9 天打網球 yes、5 天 no：

`Gini(S)=1−(9/14)²−(5/14)²≈0.459`。

投影片示範用 Outlook 分組，把 Sunny 與 Rain 合併成 10 筆（5 yes、5 no），Overcast 是 4 筆（4 yes、0 no）：

- `Gini(Sunny/Rain)=1−(5/10)²−(5/10)²=0.5`
- `Gini(Overcast)=0`
- 加權 Gini = `(10/14)×0.5 + (4/14)×0 = 0.3571`

切分後加權 Gini 比原本 0.459 低，表示這個切分讓資料較純。CART 通常挑加權子節點 Gini 低的二元切分。迴歸樹則預測數值，可用平方誤差等準則。Postpruning 是先長樹再刪除對新資料幫助不大的枝條。

### 3. 混淆矩陣：照影片數字手算

投影片例子：TP=63、FP=28、FN=37、TN=72，總共 200 筆。

- Recall／Sensitivity／TPR = `TP/(TP+FN)=63/100=0.63`
- FPR = `FP/(FP+TN)=28/100=0.28`
- Specificity = `TN/(TN+FP)=72/100=0.72`
- Precision／PPV = `TP/(TP+FP)=63/91≈0.69`
- F1 = `2×Precision×Recall/(Precision+Recall)≈0.66`
- Accuracy = `(TP+TN)/200=135/200=0.675`，約 **67.5%**；投影片把它四捨五入顯示約 0.68。

先固定正類再放格子：TP 真正例、FN 漏掉正例、FP 誤報正例、TN 正確判負。若罕見疾病一百人中只有五個病人，全判為沒病也有 95% accuracy，卻完全抓不到病人，所以不能只看 accuracy。

### 4. ROC、估計方法、Bagging、Boosting、Feature selection

- **ROC**：改變判正門檻，縱軸 TPR、橫軸 FPR。往左上通常較好；AUC 概括不同門檻的排序能力。
- **效能估計**：訓練資料用來學、未參與訓練的資料用來估新資料表現。可用 hold-out 或 K-fold cross-validation；不讓最終 test data 參與調參，也避免標準化／選特徵偷看 test。
- **Bagging**：每棵模型用 bootstrap 有放回抽樣，再投票／平均以降低變異。抽 N 次時，一筆資料至少沒被抽到的機率約 `(1−1/N)^N≈1/e`，所以每個 bootstrap 樣本約含 63.2% 不重複原始資料，約 36.8% 原資料成為 out-of-bag。
- **Random forest** 在 Bagging 樹以外，每次切分還隨機挑一部分特徵，讓樹之間更不同。
- **Boosting** 依序訓練，後面模型著重前面難分的資料／殘差；Bagging 則獨立訓練後再聚合。
- **Feature selection**：從原始預測特徵中挑一個較小子集，讓分類效能好又容易理解，可減少過度擬合和運算。它挑的是原欄位；PCA 則創造新的組合特徵。

## 八、Naïve Bayes 與 Laplace

貝氏分類把類別先驗機率與特徵的似然相乘比較。Naïve 假設：給定類別後，各特徵條件獨立。連續特徵如體溫可用常態分布估密度；計數或二元資料則使用對應的離散分布。

若某類某特徵從未出現，原始估計為 0；Naïve Bayes 將多個似然相乘會因此整個歸零。影片的 Laplace add-one：分子加 1，分母加此欄位可能值數 q：

`P̂=(該值在該類出現次數+1)/(該類資料數+q)`。

若某類 10 封信中某詞出現 0 次、詞彙是否出現只有 2 種狀態，平滑機率為 `(0+1)/(10+2)=1/12`，而不是 0。

## 九、KNN 與 SVM

**KNN** 對新樣本找最近 K 筆再投票。K 小容易被雜訊騙，K 大可能把不同群混在一起；距離受尺度與特徵影響，高維時鄰近遠近會變得不清楚，資料量大時計算也慢。

**SVM** 在可分資料中找最大 margin 的分界面；最靠近邊界、決定邊界位置的樣本叫 support vectors。軟間隔允許部分錯誤以換較穩定的邊界；Kernel trick 可處理非線性資料。多類別問題常拆成 one-vs-rest 或 one-vs-one 等多個二元 SVM 再整合。

## 十、GLM：Random component 與勝算／Logit

GLM 可分三部分：

1. **Random component**：答案 Y 的機率分布。
2. **System component**：解釋變數的線性組合 `η=β₀+β₁x₁+...`，也能放交互作用、平方項。
3. **Link function**：把平均結果連到 η，例如 `g(E[Y|X])=η`。

影片列的對應：常態連續反應用線性模型；二元成功／失敗用 Binomial 與 Logistic Regression；固定時間／區域的事件數用 Poisson Regression；若 count 資料變異數大於平均、呈 overdispersion，可用 Negative Binomial；正值且右偏、變異隨平均增加的連續資料可考慮 Gamma。影片也列 survival time 與 Cox model。

二元 Logistic 使用 logit link：

`log(π/(1−π)) = β₀+βX`，其中 π=P(Y=1)。勝算 odds 是 `π/(1−π)`，成功機率 0.8 時 odds=4；logit 是 odds 取自然對數。Logistic regression 的線性部分是 log-odds，不是直接把機率 π 做線性加減。
