# DATAMININ 資料探勘觀念字卡

## 直接開始練習

[開啟 DATAMININ｜78 題資料探勘觀念練習](https://xxoon0987.github.io/xooon0987.github.io/dataminin/)

在其他電腦打開上方連結即可練習。作答紀錄存在目前瀏覽器，換電腦時可用網站內的「學習紀錄」匯出與匯入。

靜態網站，直接放在 GitHub Pages 的 `dataminin/` 目錄即可使用。免安裝、免登入、無後端。

## 題庫

- 78 題補充觀念四選一，涵蓋基礎與資料型態、前處理與相似度、關聯規則、分群、降維與特徵、分類與評估。
- 依使用者先前的 65 題練習、2026-10-21 資料探勘導論複習筆記重新編寫。為了練熟名詞，核心概念會重複出現；題目改用不同情境、比較與反向判斷。特別加強 Ward、PCA、gain ratio 等曾追問的概念。
- 不含計算題，也不是老師原題。考試範圍未正式公布；降維與分類屬已上傳教材的延伸章節。
- 題面只顯示精簡選項。作答後揭曉對錯，可查看正解與其他三項各自不適用的原因。
- 題序與選項每回合重排，A／B／C／D 的正解位置在一回合內平均分配；正解不會固定落在最長選項。

## 錯題與紀錄

- 每次作答都以 `localStorage` 儲存在目前瀏覽器，包含題目、所選選項、作答時間與對錯。
- 錯題本顯示上次錯選、正確答案、累計錯誤次數與逐項詳解。
- 曾答錯的題目在後續回合連續答對兩次後，才從「待加強」移出；歷史紀錄仍保留。
- 可以練待加強題、所有曾錯題，或按章節練習。
- 學習紀錄可匯出為 JSON，換瀏覽器或裝置時可匯入並合併。網站不會將作答資料上傳到 GitHub 或其他伺服器。

## 本機預覽

在這個資料夾執行 `python3 -m http.server 8765`，再開啟 `http://localhost:8765/`。網站採原生 HTML/CSS/JavaScript，沒有建置步驟。
