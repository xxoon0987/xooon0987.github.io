# DATAMININ｜資料探勘考試重點與題庫 1105

[直接開啟練習網站 1105](https://xxoon0987.github.io/xooon0987.github.io/dataminin/)

依使用者 2026-11-03 提供的四張「資料探勘期中考」重點照片重新整理。網站是 GitHub Pages 靜態網站，免安裝、免登入，在手機或其他電腦都能開啟。

## 新版內容

- 「考試重點」整理 10 章、55 個可辨識考點。每張卡片都有白話說明、實際例子與易混淆提醒。
- 也可在 GitHub 直接閱讀完整的[考試重點複習筆記](./考試重點複習.md)。
- 另有依 37 分鐘課堂影片整理的[影片考試詳細複習講義 1105](./影片考試詳細複習.md)，附影片例題與觀念解說。
- 新版題庫共 101 題，涵蓋導論、資料與相似度、降維、關聯法則、前處理、分群、決策樹與評估、貝氏分類、KNN／SVM／GLM。
- 題型預設「只練觀念」，可練 93 題。照片另提到階層式分群會考一些計算，且列出卡方與貝氏計算，因此另有 8 題簡短應用題，可切換「觀念＋少量計算」。
- 每題四選一，作答後顯示對錯；四個選項各有解釋。題序與選項每回合重排，正解不固定在較長選項。
- 原本的 78 題補充題仍可從「題庫」選單練習。新版使用新的題目 ID，既有錯題紀錄不會被覆蓋。

照片中降維第 1 項是無法辨識的投影片照片，沒有擅自補寫。部分只有標題、缺少課堂上下文的考點（例如 `Whole Regression Methods`）已在重點卡片註明解讀範圍，仍應以老師的投影片為準。

## 錯題與紀錄

- 每次作答都以 `localStorage` 儲存在目前瀏覽器，包含題目、所選選項、作答時間與對錯；舊版與新版紀錄都保留。
- 錯題本顯示上次錯選、正確答案、累計錯誤次數與逐項詳解。
- 曾答錯的題目在後續回合連續答對兩次後，才從「待加強」移出；歷史紀錄仍保留。
- 可練待加強題、所有曾錯題，或按章節練習。
- 學習紀錄可匯出為 JSON，換瀏覽器或裝置時可匯入並合併。網站沒有帳號或雲端同步，作答資料不會自動上傳到 GitHub。
