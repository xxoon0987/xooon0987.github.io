## 一、多元線性迴歸：每個係數的意思

多元線性迴歸用多個 X 一起預測一個 Y，例如用房屋坪數、房間數、樓層數預測房價：

`房價 = 截距 + β₁×坪數 + β₂×房間數 + β₃×樓層數 + 誤差`

單一係數 `β₂` 的意思是：**在其他 X 固定時，房間數增加一單位，模型預測房價平均改變多少。**這是「控制其他變項後的效果」，不是房間數和房價單獨的相關。

### 為什麼係數方向可能和直覺相反？

大房子通常房間比較多，而且房價也較高。因此只看兩欄的相關，房間數和房價可能是正相關。但坪數和房間數也彼此相關；多元迴歸要先把坪數能解釋的部分算進去，再問「同樣坪數的房子，多一間房代表什麼」。同坪數多一間房，可能代表每間房更小，於是控制坪數後，房間數的係數可能變小、接近零，甚至轉成負值。

這不是數學矛盾，而是兩個問題不同：

- 單獨相關：坪數大的房子是不是通常房間多、房價高？
- 多元迴歸係數：在坪數相同時，房間數多一間的房子，預測房價如何改變？

當 X 彼此高度相關，稱為**多重共線性**。它可能讓個別係數的大小和正負對資料的小變動很敏感，標準誤變大，難以說清楚每個欄位各自貢獻多少。整體預測有時仍然不錯，但個別係數的解讀會不穩。

### 一個容易混淆的說法

錄音中老師提到迴歸會把各欄位的貢獻拆開來看。精確地說，普通最小平方法**不要求所有預測欄位彼此獨立**；欄位高度相關仍可估計，但係數可能不穩。若欄位完全由其他欄位線性組合而成，才會造成完全共線性，係數無法唯一估計。迴歸常見的獨立性假設主要指誤差／觀測的結構，不能簡化成「X 必須互相獨立」。

## 二、正則化：為什麼要替係數加懲罰？

普通迴歸會找一組係數，讓預測誤差盡量小。若欄位很多、彼此重疊或資料有雜訊，模型可能把偶然模式也學進去。**正則化（regularization）**是在原本的誤差之外，加上一項係數懲罰：

`總目標 = 訓練資料誤差 + λ × 係數懲罰`

懲罰會限制係數不要大到不必要，通常可降低模型對資料微小變化的敏感度，減少過度擬合。`λ` 控制懲罰強度：太小效果有限；太大會把重要效果也壓掉，造成欠擬合。實務上可用驗證資料或交叉驗證挑選 `λ`。這段是幫助理解的背景；錄音主要強調三種方法的差別，沒有要求手算公式。

正則化通常需要先留意特徵尺度。若一欄以公尺計、另一欄以毫米計，同樣的實際變化會有不同數字，係數懲罰可能不公平；因此 Ridge、Lasso、Elastic Net 常搭配標準化。截距通常不納入懲罰。

## 三、Ridge、Lasso、Elastic Net 的差別

| 方法 | 使用的懲罰 | 係數會怎樣 | 適合什麼情況 | 一句記法 |
|---|---|---|---|---|
| Ridge（L2） | 係數平方和 `Σβ²` | 把係數縮小，通常不會精確變成 0；保留所有欄位 | 很多欄位都有一些用處，或欄位彼此相關、希望估計穩定 | **留著欄位、把權重縮小並分散** |
| Lasso（L1） | 係數絕對值和 `Σ|β|` | 可能把部分係數直接壓成 0，達到特徵選擇 | 想得到較精簡的欄位集合 | **能把不重要欄位刪成 0** |
| Elastic Net | L1 與 L2 混合 | 能把部分係數壓成 0，也有 L2 的穩定／群組效果 | 欄位很多且彼此相關，也想選出較少欄位 | **Lasso 的選擇性＋Ridge 的穩定性** |

### 1. Ridge：縮小係數，不以刪欄位為主

Ridge 的 L2 懲罰會懲罰很大的係數。若幾個欄位都在描述相近資訊，例如坪數和房間數都能反映房屋大小，Ridge 通常能減少係數全押在其中一欄的情況，使整體估計較平滑、穩定。老師用「團隊一起完成工作，再把成果分給團隊成員」作比喻：不要把貢獻全部算到一個欄位身上。

但 Ridge 通常不會把欄位係數精確設成 0，所以它**不太會產生很稀疏的模型**。若題目問哪一個方法常保留所有欄位、只縮小係數，選 Ridge。

### 2. Lasso：把一些係數壓成 0

Lasso 使用 L1 懲罰，除了縮小係數，也可能讓部分係數恰好等於 0。係數為 0 的欄位便不再參與預測，所以 Lasso 有**內建特徵選擇**的效果。

老師用挑選重要欄位／員工的比喻：模型從一批候選欄位中留下較有用者，其他係數壓到 0。錄音也明確提到，若希望最後留下較少欄位，Lasso 比 Ridge 更符合這個目標。

注意：Lasso 面對高度相關的欄位時，可能只挑其中一個，選擇結果會受資料影響；不能因此斷定被刪的欄位在所有情況下都完全沒有價值。

### 3. Elastic Net：同時用 L1 和 L2

Elastic Net 把 Lasso 的 L1 和 Ridge 的 L2 懲罰合在一起。它可以把部分係數壓到 0，留下較少欄位；同時對一群彼此相關的欄位，通常比純 Lasso 更穩定。

簡單的考試辨認：

- 問「哪個會做變數選擇、係數變成 0？」→ Lasso。
- 問「哪個主要縮小係數但多半保留全部欄位？」→ Ridge。
- 問「同時有稀疏選擇與 Ridge 式穩定效果？」→ Elastic Net。

## 四、固定資料集的訓練／測試，和持續到來的資料

在一般作業資料中，可以先分訓練集和測試集：訓練集用來估計模型，測試集用來評估未見資料上的效果。測試資料不可拿來訓練，否則評估會過度樂觀。

實際公司資料常會每天增加，例如推薦系統每天收到新的瀏覽、點擊與購買。若每次都從頭拿幾十年歷史資料重新訓練，計算和保存成本可能很高。老師接著介紹 **Incremental Learning（增量學習／增量式學習）**：模型可以依新資料逐步更新，不一定每次都從頭重訓全部歷史資料。

**例子：** 推薦系統先用已有的商品互動學習使用者偏好；新的一筆點擊或購買進來後，模型更新使用者或商品的狀態，讓後續推薦反映較新的行為。

增量學習不是「任何模型都可以只記住新資料而忘掉舊資料」；具體如何更新、保留多少舊資訊，取決於演算法。正式上線仍要用新資料評估模型，留意使用者偏好或資料分布改變。
